# Controls

Any controller SDL knows (Xbox, PlayStation, Switch Pro and most others) works
as the Xbox pad; plug it in before or during play. Rumble goes to the same
controller. The keyboard works at the same time as a controller.

## Controller

| Xbox button | Modern controller |
|---|---|
| A, B, X, Y | A, B, X, Y (Cross, Circle, Square, Triangle) |
| Black | Left bumper |
| White | Right bumper |
| Left / right trigger | Left / right trigger |
| Left / right stick, click | Left / right stick, click |
| D-pad | D-pad |
| Start | Start / Menu / Options |
| Back | Back / View / Share |

## Keyboard

| Xbox button | Key |
|---|---|
| Left stick | W A S D |
| Right stick | Numpad 8 4 5 6 |
| D-pad | Arrow keys |
| A | Space or K |
| B | L |
| X | J |
| Y | I |
| Black | E |
| White | R |
| Left trigger | Q |
| Right trigger | Shift |
| Left / right stick click | F / G |
| Start | Enter |
| Back | Backspace |

## Window keys

| Key | |
|---|---|
| F11 or Alt+Enter | Fullscreen on / off |
| F10 | Frame rate on / off |
